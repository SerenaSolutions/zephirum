# The Decision Layer Strategy (founder directive, 2026-10-14)

ZEPHIRUM does not compete with any programming language — classical or quantum.
From this stage forward, the product is THE DECISION LAYER:

Any language, any stack, any service that needs exact, auditable verdicts
embeds the ZYQL gate as a plugin:

- c-api/zyql.c — one .c file, one .h file, ZERO dependencies (SQLite-style core):
  any language that can call C can decide-and-prove.
- Trivalent semantics: 1 / 0 / REFUSED — with REFUSED being a first-class,
  signed answer, not an error.
- Every verdict sealed: ML-DSA-44 receipt in a tamper-evident hash chain
  (nonce, timestamp, seq, prev-hash).
- Prohibited-purpose portgate classified before compute (EN+PT+ES today,
  extensible word lists — issue #4).

We are not the language the world replaces others with.
We are the decision layer the whole world plugs into.
